# IntentFlow AI — Experimentation & Statistical Inference Design

## 1. Overview & Objective
IntentFlow AI provides an enterprise-grade A/B experimentation platform built to measure the statistical lift of personalized website variants generated by LangGraph agents against baseline controls.

This document describes the mathematical formulation, visitor allocation methodology, event tracking pipeline, and statistical decision rules implemented in `services/experiment_service.py`.

---

## 2. Deterministic Traffic Allocation (MD5 Hash Partitioning)

### 2.1 Methodology
Rather than relying on non-deterministic client-side randomizers, IntentFlow AI utilizes deterministic hashing:
$$\text{hash\_val} = \text{MD5}(\text{experiment\_id} + ":" + \text{visitor\_id})$$
$$\text{slot} = \frac{\text{int}(\text{hash\_val}[0:8], 16) \pmod{10000}}{10000.0}$$

### 2.2 Guarantees
- **Sticky Assignments**: A returning visitor with the same `visitor_id` is guaranteed to receive the identical variant without requiring stateful browser cookie lookups on each request.
- **Uniform Distribution**: MD5 bit dispersion ensures uniform probability coverage across configured traffic split ratios (e.g., 50% Control, 50% Variant A).
- **Independent Experiment Partitions**: Salted with `experiment_id` to eliminate assignment correlation across distinct experiments.

## 3. Statistical Testing Framework

### 3.1 Hypotheses
For control conversion rate $p_c$ and variant conversion rate $p_v$:
- **Null Hypothesis ($H_0$)**: $p_v - p_c \le 0$ (Variant does not improve conversion).
- **Alternative Hypothesis ($H_1$)**: $p_v - p_c > 0$ (Variant improves conversion).

### 3.2 Two-Proportion Pooled Z-Test
When evaluating $n_c$ visitors with $x_c$ conversions, and $n_v$ visitors with $x_v$ conversions:
$$\hat{p}_c = \frac{x_c}{n_c}, \quad \hat{p}_v = \frac{x_v}{n_v}$$

The pooled proportion $\hat{p}$ is:
$$\hat{p} = \frac{x_c + x_v}{n_c + n_v}$$

The standard error under $H_0$ is:
$$SE_{\text{pooled}} = \sqrt{\hat{p}(1 - \hat{p})\left(\frac{1}{n_c} + \frac{1}{n_v}\right)}$$

The test statistic $z$ is:
$$z = \frac{\hat{p}_v - \hat{p}_c}{SE_{\text{pooled}}}$$

### 3.3 Two-Sided P-Value & Normal CDF Approximation
To guarantee zero-external-dependency execution in Python without requiring heavyweight scipy binaries:
$$p\text{-value} = 2 \times (1 - \Phi(|z|))$$
Where $\Phi(x)$ is approximated using the polynomial normal cumulative distribution function (Abramowitz & Stegun):
$$\Phi(x) = 1 - Z(x)(b_1 t + b_2 t^2 + b_3 t^3 + b_4 t^4 + b_5 t^5)$$
with $t = \frac{1}{1 + 0.2316419 x}$.

### 3.4 95% Confidence Interval of Difference
The unpooled standard error for confidence interval estimation:
$$SE_{\text{diff}} = \sqrt{\frac{\hat{p}_c(1 - \hat{p}_c)}{n_c} + \frac{\hat{p}_v(1 - \hat{p}_v)}{n_v}}$$
$$\text{CI}_{95\%} = \left[(\hat{p}_v - \hat{p}_c) - 1.96 \times SE_{\text{diff}}, \; (\hat{p}_v - \hat{p}_c) + 1.96 \times SE_{\text{diff}}\right]$$

## 4. Decision Rules & Guardrails

1. **Sample Size Warning**:
   If either $n_c < 100$ or $n_v < 100$, IntentFlow flags `sample_size_warning: true` in the API payload and UI to prevent premature stopping on low-powered results.
2. **Significance Threshold**:
   $p\text{-value} < 0.05$ with $z > 0$ and lower bound of $\text{CI}_{95\%} > 0$ is required to designate a variant as a statistically significant winner.
3. **Lift Calculation**:
   - Absolute Lift: $\Delta = \hat{p}_v - \hat{p}_c$
   - Relative Lift: $\text{Lift}_{\text{rel}} = \frac{\hat{p}_v - \hat{p}_c}{\hat{p}_c}$

## 5. Synthetic Traffic Simulator
To support technical demonstrations and automated integration tests:
- Given target visitor counts $N$ and target conversion rates $p_c$ and $p_v$:
- Generates synthetic exposures and conversions using deterministic seeds or binomial distribution sampling.
- Updates database tables `experiment_assignments` and `experiment_events` within transactional blocks.
